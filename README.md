All tables with data now have a script, but Tables 21, 24, 28 and 29 are rebuilt from the text and only approximately reproduced. Table 29a (Table A in the article) uses the original scripts in code/pendulum_video; its input files are not included.

Requirements: Python 3, numpy, scipy. Tables 1, 4, 5, 25, 26 and 34 need no data files; Tables 2, 3 and 27 need only the files in this folder. Tables 6 to 13 need the public multi-arm pendulum data (dynamicslab/multiarm-pendulum, TriplePendulum folder), whose path is set at the top of code/pendulum_triple/tri.py; the data are not included here. Table 29a needs the 19 supplied video-tracked pendulum files (16 distinct runs; not included, source unknown); set the folder at the top of code/pendulum_video/load.py and run pt1.py, then pt2.py, with Python 3, numpy, scipy and the lawsample package on the path. Table 29 needs the Schmidt-Lipson archive files (not included here, third-party) and the lawsample package.

Size note: the six simulated-run data files (sim_run1-3.npz, simB_run1-3.npz, 14 MB each) are left out of this copy. The scripts sim_gen.py and simB_gen.py write them; that regeneration was not checked to give identical files, so the Table 14 to 17 scripts were verified against the original files, not against regenerated ones.

Version: this folder accompanies the monograph (manuscript version 32) and the article of 8 November 2026. Output files are listed with SHA-256 checksums in CHECKSUMS.txt, so that a re-run can be compared byte for byte.
